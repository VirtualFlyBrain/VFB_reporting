
# curation_record_scripts:
    Scripts for generating curation records from reports (L1EM and FAFB).
    
## anat_curation_file_maker:
    Makes image curation record(s) for new skids in VFB_reporting_results/<site>_new_skids.tsv.
    
## newmeta_curation_file_maker (removed):
    FBbt typing records for FAFB and L1EM CATMAID neurons are now made by
    connectome-curation (https://github.com/VirtualFlyBrain/connectome-curation,
    `vfb-curation run fafb` / `vfb-curation run l1em`).
